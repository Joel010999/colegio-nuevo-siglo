📥 Importar Deudas desde Excel del Sistema del Colegio

✅ Formato del Colegio Detectado Automáticamente
El sistema reconoce automáticamente el archivo Excel que exporta el sistema del colegio con las siguientes columnas:
Familia Documento Apellido Nombres Niv Cur Div 0_Matrícula 1_Cuota ... 10_Cuota 20_Material Didactico etc...
💡 ¿Cómo funciona?
  • El sistema toma las columnas de Documento, Apellido, Nombres, Niv, Cur, Div para identificar alumnos
  • Cada columna de concepto (ej: 0_Matrícula, 1_Cuota) se convierte en una deuda individual
  • Solo se importan celdas con valores mayores a 0
  • Se crean usuarios automáticamente con el DNI como nombre de usuario
